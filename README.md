# goit-core-hw-07

Консольний бот-помічник на Python 3.10+. Сторонні бібліотеки не потрібні.

## Запуск

```bash
python main.py
```

## Команди

| Команда | Дія |
| --- | --- |
| `hello` | Привітання |
| `add <name> <phone>` | Створити контакт або додати йому телефон |
| `change <name> <old_phone> <new_phone>` | Замінити телефон |
| `phone <name>` | Показати телефони контакту |
| `all` | Показати всі контакти |
| `add-birthday <name> <DD.MM.YYYY>` | Додати або замінити день народження |
| `show-birthday <name>` | Показати день народження |
| `birthdays` | Показати найближчі привітання |
| `close` або `exit` | Завершити програму |

Ім’я вводиться одним словом; регістр імен має значення. Телефон повинен
містити рівно 10 цифр. Дані зберігаються в пам’яті протягом сеансу.

`AddressBook.get_upcoming_birthdays()` повертає список словників з ключами
`name` і `birthday`. Перевіряються сьогодні та наступні шість календарних днів.
Привітання із суботи й неділі переносяться на понеділок, навіть якщо він
виходить за межі цього періоду. У невисокосні роки 29 лютого відзначається
28 лютого. Контакти без дати народження пропускаються.

## Приклад

```text
add Anna 0501234567
add-birthday Anna 25.10.1995
show-birthday Anna
birthdays
all
exit
```
